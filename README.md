### 🚀 Featured Projects

**[SnapClass](https://github.com/VaishnaviJagtap18/snapclass-app-main)** — AI classroom attendance
Marks attendance from a single class photo or audio clip instead of a roll call. Face recognition runs on dlib (HOG detector + 128-d embeddings) classified with an SVM; voice recognition runs on resemblyzer with cosine similarity matching. Teacher/student roles, QR auto-enroll, Supabase backend.
`Python` `Streamlit` `dlib` `resemblyzer` `Supabase`
🔗 [Live demo](https://snapclass-intelligentai-attendance.streamlit.app)

**[AI ATS Resume Analyzer](https://github.com/VaishnaviJagtap18/AI_ATS_Resume_Analyzer)** — resume scoring against real ATS criteria
Scores resumes out of 100 across five weighted components (formatting, keywords, content, skill validation, ATS compatibility), matches against a pasted job description using keyword + semantic similarity, and flags privacy risks like exposed addresses. FastAPI backend, spaCy + sentence-transformers for NLP, Streamlit frontend, PDF report export.
`FastAPI` `spaCy` `sentence-transformers` `Supabase` `WeasyPrint`

**[AI Gym Workout Coach](https://github.com/VaishnaviJagtap18/AI_GYM_Workout_Coach)** — real-time form-checking trainer
Counts reps and checks form live through a webcam using MediaPipe pose landmarks and joint-angle math, across five exercises (squat, push-up, lunge, shoulder press, bicep curl). A Groq-hosted LLM generates spoken coaching feedback via TTS as you train.
`MediaPipe` `OpenCV` `Streamlit-WebRTC` `Groq LLM`

**[NeuralCanvas — AdaIN Style Transfer](https://github.com/VaishnaviJagtap18/NeuralCanvas-AdaIN)** — real-time neural style transfer
Implements Adaptive Instance Normalization (Huang & Belongie, 2017) to restyle any photo in a single forward pass, no per-image optimization. PyTorch VGG encoder + trained decoder, Flask web app with an alpha slider to blend content and style.
`PyTorch` `Flask` `Computer Vision`
🔗 [Live demo](https://neuralcanvas-adain-2.onrender.com)

**[Customer Churn Prediction](https://github.com/VaishnaviJagtap18/customer-churn-prediction)** — production-ready ML pipeline
End-to-end churn pipeline: data cleaning, feature engineering, model selection (XGBoost), FastAPI deployment, and automated drift monitoring.
`XGBoost` `FastAPI` `scikit-learn` `MLOps`
